# Architecture Decision Records

Lightweight ADRs for durable choices in this package. One file per decision,
named `NNN-kebab-case-title.md`, with OKF frontmatter of `type: Architecture`.

No ADRs have been written yet. The decisions that predate this bundle are
described in [System Overview](/architecture/system-overview.md).

Add an ADR when a choice is costly to reverse: a schema change, a public API
signature, or a dependency that the host application inherits.
