# Schema

Table `v_rules`. Model `ThreeLeaf\ValidationEngine\Models\Rule`.

| Column       | Type      | Notes                                                              |
| ------------ | --------- | ------------------------------------------------------------------ |
| `rule_id`    | UUID      | Primary key. Generated by `HasUuids`.                              |
| `attribute`  | string    | The data key this rule checks, for example `state` or `date_time`. |
| `rule_type`  | string    | Fully qualified class name that extends `ValidationEngineRule`.    |
| `parameters` | JSON      | Constructor arguments for that class.                              |
| `created_at` | timestamp | Database default `useCurrent()`.                                   |
| `updated_at` | timestamp | Database default `useCurrent()`, `useCurrentOnUpdate()`.           |

The migration declares `parameters` as a `json` column. The model casts it with
`'parameters' => 'json'`, so PHP code reads and writes an array.

## Casts

`rule_type` uses [`ClassCast`](/features/rule-persistence-and-instantiation.md),
parameterized with `ValidationEngineRule::class`. On write, the cast rejects any
value that is not a class extending, implementing, or using that type. The check
runs before the row reaches the database.

## Fillable

`attribute`, `rule_type`, `parameters`. `rule_id` is not fillable; the trait
supplies it.

## Behavior

`Rule::instantiateRule()` turns the row into a live rule object. It re-checks
`class_exists()` and `is_subclass_of()` and throws `InvalidArgumentException`
when either fails, then calls the static `make()` factory with the stored
parameters. See [Rule Persistence and Instantiation](/features/rule-persistence-and-instantiation.md).

# Examples

```php
use ThreeLeaf\ValidationEngine\Models\Rule;
use ThreeLeaf\ValidationEngine\Rules\EnumRule;

$rule = Rule::create([
    'attribute'  => 'active_status',
    'rule_type'  => EnumRule::class,
    'parameters' => [
        'enumClass'     => \ThreeLeaf\ValidationEngine\Enums\ActiveStatus::class,
        'allowedValues' => ['Active'],
    ],
]);
```

The `parameters` keys must match the rule class constructor parameter **names**.
`EnumRule` takes `$enumClass` and `$allowedValues`, so those are the keys.
